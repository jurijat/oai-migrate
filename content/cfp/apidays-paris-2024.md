# **OpenAPI track at apidays**

The OpenAPI and Arazzo specifications are an integral part of development and delivery of APIs. OpenAPI is continuing to expand partnerships with multiple API related conferences by providing an OpenAPI track. This will allow presenters on the OAI track to focus on how OpenAPI is relevant to the focus of the conference. By being part of multiple conferences there will be far more opportunity for the API community to understand how OpenAPI can help them achieve their API goals. This will benefit OpenAPI as it increases the opportunity to receive feedback on what improvements to the spec are most needed.

# **Call for proposals: [API Days Paris 2024](https://apidays.typeform.com/to/ILJeAaV8#event_name=xxxxx)**

The OpenAPI Initiative (OAI) is soliciting submissions for a specific “OAI Track” at API Days Paris 2024. The goal of this track is to provide a forum where practitioners can share and exchange information about their use of the OpenAPI specifications, about tools that they are using or building, or about extensions or augmentations of the specifications that may be of interest to the API community.

**Specifically, we are encouraging submissions with the following topics and themes:**

-   Scenarios where OpenAPI specifications are used for individual APIs or API landscapes to help with any step along the entire API lifecycle.
-   Tools and usage patterns where OpenAPI plays an important role in using the tool and/or scaling the usage across large API landscapes.
-   Aspects of working with APIs which are not covered by OpenAPI but could benefit from having standardized representations for interoperability and open exchange.
-   Specific OpenAPI extensions that have the potential to become useful for a larger set of scenarios or user groups.
