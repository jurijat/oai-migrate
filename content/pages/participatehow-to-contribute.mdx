The OpenAPI Specification is a vendor-neutral, open-source API description that was originally based on the Swagger Specification, donated by SmartBear Software. The API community – architects, vendors, and any organization leveraging the API economy – is welcome to participate in the evolution of the OpenAPI Specification (OAS).

**Evolve the Spec**

-   Participate at GitHub: [https://github.com/OAI/OpenAPI-Specification](https://github.com/OAI/OpenAPI-Specification)
    -   [Next Proposals](https://github.com/OAI/OpenAPI-Specification/labels/OpenAPI.Next%20Proposal)
    -   Looking for a specific topic? Look [here](https://github.com/OAI/OpenAPI-Specification/labels)

Not sure how to get started? Read how to participate [here](/news/blogs/2016/07/you-can-get-involved-creating-openapi-specification-and-heres-how)

**Leverage the Spec**

There are no membership, or fees required to leverage the OpenAPI Specification.

-   Find the latest version on our GitHub repo [here](https://spec.openapis.org/oas/latest.html), and find all versions [here](https://github.com/OAI/OpenAPI-Specification/tree/master/versions).
-   Already leveraging the OpenAPI Spec? We want to hear about! Tweet your implementation tagged with @OpenApiSpec and show off your work.

**Learn More About the Spec**

Whether you are just entering the API economy, or a longtime standard bearer. There is also something new to learn about the OAS
